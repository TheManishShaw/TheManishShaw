## About me

I'm a frontend developer based in Kolkata, India, focused on turning thoughtful product ideas into polished, high-performance interfaces. I enjoy creating responsive web applications with modern JavaScript frameworks, strong UI engineering practices, and useful AI capabilities.

I’m especially interested in the intersection of frontend development and generative AI: designing intuitive AI features, integrating model APIs, and writing clear prompts that make AI-powered products more reliable and helpful.

- Building scalable, user-centred web applications
- Exploring modern React, Next.js, TypeScript, and full-stack frontend patterns
- Integrating generative AI for search, assistants, content workflows, and personalization
- Improving accessibility, performance, design systems, and developer experience

## Core stack

**Frontend:** JavaScript, TypeScript, React, Next.js, HTML5, CSS3, Tailwind CSS, Material UI

**Frontend engineering:** Responsive design, accessibility (a11y), component architecture, state management, REST APIs, performance optimization, SEO, testing, Git, and CI/CD

**Backend & data:** Node.js, Firebase, MongoDB, MySQL

**Design & collaboration:** Figma, Adobe Photoshop, GitHub

## AI & generative AI

- **AI product integration:** Connecting web applications with AI APIs to build intelligent search, chat, summarization, content generation, and workflow automation.
- **Prompt engineering:** Designing structured, context-aware prompts with clear goals, constraints, examples, and evaluation criteria.
- **Conversational UX:** Creating helpful, transparent chat experiences that make AI features feel natural and easy to use.
- **Responsible AI:** Considering privacy, accuracy, guardrails, human review, and clear user feedback when designing AI-enabled interfaces.
